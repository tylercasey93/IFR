# The Meridian Files

A three-book aviation-thriller/friends-to-lovers-romance series, narration-ready prose that teaches the FAA Instrument Rating ACS through the story. Captain Cole Bishop and First Officer Jack Marsh fly for Meridian Air Charter — until an account they don't fully understand turns their crew into cover for an intelligence operation, and two years of a rule Cole won't break start coming apart in real time.

**Start here, in order:**
1. `SERIES-BIBLE.md` — locked author decisions (numbered, versioned; later numbers override earlier ones on the same topic) and the craft-calibration log.
2. `CHARACTERS.md` — full dossiers for the cast: timeline, psychology, voice, series arc, canon anchors.
3. `BOOK-1-OUTLINE.md` — the 21-chapter map for Book 1.
4. `book-1/` — the manuscript itself, as far as it's gotten.

`draft-one/` is an earlier, superseded single-book version of this story with a different cast — kept as historical record only, not canon.

`narration/` has the audio-production pipeline (`PRODUCTION.md`) and, once chapters are recorded, the rendered mp3s in `narration/output/`.

This repo split off from a larger monorepo (`tylercasey93/IFR`) that also holds an unrelated Instrument Rating study app and its ACS reference wiki — full history from when this project lived there is preserved in this repo's git log.

See `CLAUDE.md` for the full writing and narration workflow.
