# Draft One (superseded)

This folder holds **Draft One** — the original single-book version of this story ("Cleared as Filed"), written before it became the three-book *Meridian Files* series. It has a different cast: Wren Hale as captain and "Theo Marsh" as first officer, rather than the current Cole Bishop / Jack Marsh pairing.

It's kept here as historical record only. Do not extend it, and do not treat it as canon — the locked canon is `../SERIES-BIBLE.md`, `../CHARACTERS.md`, and `../BOOK-1-OUTLINE.md`. The active manuscript is `../book-1/`.
